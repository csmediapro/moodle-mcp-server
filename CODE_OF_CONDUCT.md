# Code Of Conduct

This project uses a simple standard: be direct, respectful, and useful.

We welcome issues, questions, bug reports, and contributions from people using Moodle, MCP clients, local models, hosted models, and related LMS reporting workflows.

Unacceptable behavior includes harassment, personal attacks, doxxing, spam, and disclosure of private Moodle/customer data.

Report concerns to contact@csmediapro.com.
